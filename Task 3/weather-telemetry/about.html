About

Real-Time Weather Forecast & Climate Telemetry App

A live weather dashboard. Search any city worldwide to get current temperature, conditions with dynamic icons, humidity, wind speed, atmospheric pressure and a 5-day forecast. Loading spinners and friendly errors handle slow networks and unknown cities.

Tools used

Fetch API Async / Await OpenWeatherMap API CSS Flexbox

Pages

  • Dashboard: current weather metrics and the 5-day forecast cards.
  • Forecast: tap a day for a 3-hour breakdown, plus a temperature trend chart.
  • Climate: air quality index, pollutants and 5-day climate statistics.
  • Settings: API key, units (metric / imperial) and search history.

Get started

  1. Register for a free key at OpenWeatherMap.
  2. Open Settings, paste the key, press Save.
  3. Go to the Dashboard and search for a city.

How the background changes

The gradient follows the searched city's conditions: sunny, cloudy, rain, thunderstorm, snow and mist. After sunset or before sunrise in that city it switches to a night theme.
